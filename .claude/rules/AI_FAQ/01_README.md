# 연세365 Health Hub AI FAQ 공통 원칙

- 기존 lib/healthHub.ts 데이터와 URL 구조는 유지한다.
- 기존 A 패턴 상단 구조와 카테고리별 대표 이미지는 유지한다.
- B~E는 본문 sections 구성만 다르게 만든다.
- AI 생성 콘텐츠 안내는 FAQ 바로 아래에 배치한다.
- 모바일 1열, 가로 스크롤 금지, 표 대신 카드형 비교를 우선한다.
- 의료 내용은 일반 정보이며 진단·처방을 대신하지 않는다는 취지를 유지한다.
- commit, push, 배포, npm install, 환경변수 수정은 사용자 승인 없이 하지 않는다.

## 파일 사용법
Claude Code 시작 후 아래 문장을 붙여넣는다.

"AI_FAQ_MD 폴더의 모든 MD를 먼저 읽고, 연세365 Health Hub A~E 패턴 기능을 작업하세요."

## 목표
Slack 질문 접수 후 원본 제목 또는 AI 추천 제목을 선택하고, A~E 패턴 중 하나를 선택해 게시한다.
