# A~E 패턴 선택 기준

## A 기본 직접답변형
증상, 원인, 관계를 일반적으로 설명할 때 사용한다. 기존 패턴이다.

## B 체크리스트형
사용자가 확인해야 할 항목이 많을 때 사용한다. 준비, 주의, 방문 전 확인 질문에 적합하다.

## C 비교 카드형
비슷한 개념을 구분할 때 사용한다. 모바일 표 금지. 반드시 카드형으로 비교한다.

## D 단계별 FAQ형
예약, 상담, 검사, 수술, 귀가처럼 순서가 중요한 질문에 사용한다.

## E 판단 기준형
혼자 가능, 동행 확인 필요, 법정대리인 확인 필요처럼 기준을 나눠야 할 때 사용한다.
